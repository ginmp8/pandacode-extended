# PandaCode Extended documentation

This directory contains **PandaCode Extended-specific** behavior, security policies, dependency remediations, release acceptance and known issues. It is intentionally separate from upstream PandaCode documentation in `docs/`; Extended release notes live under `releases/extended/`, distinct from upstream release files at `releases/*.md`.

- [Extended 0.7.0 source-candidate documentation](0.7.0/README.md)
- [Extended 0.7.0 canonical release notes](../../releases/extended/0.7.0.md)

Do not copy these statements into upstream release notes or claim they apply to the upstream fork. A source candidate is not an installer release.
