# 0.3.35.3

This hardened release adds bounded browser quality assurance workflows, including snapshots, heuristic layout and accessibility checks, responsive viewport targets, explicit DOM interactions, finite assertions, opt-in error observation, and limited network timing evidence. It also adds approval-routed browser review tools and reusable review workflow templates.

The release includes the task tray popover and usage indicators, hardened Windows standalone-install detection, version validation improvements, and readability fixes for review checkpoint controls. Security and installation review documentation and supporting evidence have also been updated.

This is a local-packaging release candidate. Build artifacts remain local and are not uploaded. Native platform builds, provider smoke tests, and Windows/Avast verification are not claimed by these notes.
