# PandaCode 0.3.41-hardened

Selective feature release built from Hardened 0.3.35.4, with supplied upstream 0.3.41 as reference. The historical source base remains 0.3.28. No dependency version upgrades or full upstream merge.

- Named connection changes, edits and removal invalidate native resume state and preserve the visible conversation through existing context recovery. Active tasks and consoles prevent credential mutation.
- Remote Full access has a separate local setting, disabled by default and enforced at native execution admission. Device trust, revocation, replay protection and real public-key identities remain intact. Fingerprint display expands to 128 bits.
- The existing Skills library adds explicit GitHub catalog discovery, nested packages, commit-pinned imports, provenance/hash tracking, conflicts and local-drift protection.
- Bots and projects can select exact Skill versions. Effective task scopes are deduplicated and bounded; changes invalidate stale native contexts without writing bot-specific content to shared checkouts.
- Edit/Rewind creates a new task with the preceding transcript and an editable message draft. The source conversation and filesystem are not rolled back; the old native session is never resumed.
- Historical attachment chips expose validated file, image and GitHub actions.
- Agent usage separates supported subscription limits by named connection. Limit banners offer explicit compatible-account continuation. Cost estimates remain provider-wide.
- The model picker prioritizes installed agents and retains an unavailable current agent as disabled.

The optional new Cline interactive-console integration is not included. Existing providers, secure credential storage, disabled updater/installers and prior manual review/Browser QA workflows are preserved. Older standalone Codex controls that cannot honor named credentials fail closed for named tasks; see [connection limitations](../docs/connection-session-safety.md).

See the [Portuguese feature guide](../docs/HARDENED-0.3.41-GUIDE.pt-BR.md) and [validation report](../security-review/0.3.41-hardened/REPORT.md). This is a complete source distribution, not a signed native installer or a claim of complete upstream parity.
