## Extended-only changes since Extended 0.11.0

These are source-integrated **release candidates**, not published upstream PandaCode functionality.

### Added

- **[#121 — Shared Channel history per bot and channel](https://github.com/ginmp8/pandacode-extended/issues/121):** **Bot Settings → Shared Channels** now has an include-by-default bot preference and joined-channel **Use default / Include / Exclude** overrides. Explicit channel settings take precedence for newly composed assignments; saved bot-wide values remain compatible. These controls do not erase channel posts, harness history or bot memories. [Behavior and storage contract](../../docs/extended-bot-context.md).
- **[#122 — Multi-channel bot collaboration](https://github.com/ginmp8/pandacode-extended/issues/122):** Bot-owned `pandacode_bot_post_channel` creates a single informational post without dispatching tasks; `pandacode_bot_request_channel` assigns work to one or two explicit local channel members. The source includes attribution, request/delivery tracking, correlated result callbacks, idempotency handling, route-cycle rejection and a shared three-hop limit with direct bot messaging. Membership does not broadcast messages to other channels. [Tool examples and recovery guarantees](../../docs/extended-bot-collaboration.md).
- **[#123 — Declarative bot manifests and Git sync](https://github.com/ginmp8/pandacode-extended/issues/123):** Desktop JSON import/export and selected-bot export, optional native/Extended bot configuration, local Shared Channel membership/lead and supported external-channel settings. The original headless importer remains the mutation path; headless adds one-shot `pandacode serve --sync-bots bot-sources.json`. Every mutating import requires a verified, secret-free local backup. GitHub sources are pinned to commit SHA, checked for unsafe inputs and applied manually; no push or automatic polling. [Format, Desktop flow, backups and limits](../../docs/extended-bot-manifests.md).

### Changed

- The existing bot-wide **Include shared channel history** control moves from **Profile → Brain** to **Shared Channels**. **Fresh context each message** stays in Brain and remains an independent setting.
- **Profile → Instructions** includes a tooltip and collapsible communication examples; these do not change saved instructions or expand bot permissions.
- Legacy `{"bots":[...]}` manifests and original headless import/export commands are retained; optional fields enable Extended-only round-trips without making secrets portable.

### Fixed / security

- **#122 — Callback recovery:** Interrupted callback attempts now check the durable native queue/transcript before resending the correlated result, preserving idempotency without rerunning completed recipient work. Native uncertain-launch recovery still requires acceptance testing.
- **#123 — Manifest validation:** Reject malformed/unsupported Extended preferences and provider-incompatible reasoning effort before bot mutation.
- **#123 — Git sync provenance/no-op:** Include source repository/ref, content hashes and change counts; skip import when both Git manifest content and local portable configuration match the previous successful sync.
- **#121–#123 — Browser regression coverage:** Add isolated Playwright component tests and a dedicated CI job for manifest import/export and collaboration rendering. Existing history-settings browser tests remain separate; native end-to-end acceptance is pending.

_No 0.12.0-specific dependency vulnerability remediation is claimed._ Validation, read-only GitHub restrictions and verified pre-import backups are defensive behaviors in #123, not proof of an audited installer or completed release. Inherited security remediations remain tracked separately.

- **2026-11-08 — inherited PandaCode 0.3.102:** [fork source `7134edf5`](https://github.com/ginmp8/pandacode/commit/7134edf501d31acc8bec28ff74be9d1dba171669) fixed model selection when ZCode is installed: ZCode is excluded from automatic team catalogs; selecting it exits an unused team to run a single agent. ## PandaCode 0.3.103 integration — 2026-11-08

This cycle inherits [PandaCode 0.3.103](https://github.com/ginmp8/pandacode/commit/174f0c0b17ae1b036210cbc5dddf45f0701cd8b0) through [Extended source integration `3f95db51`](https://github.com/ginmp8/pandacode-extended/commit/3f95db516e607cbe6fee5585e61d09ab2c118a71); it does **not** introduce a Council feature exclusive to Extended.

- **Inherited functionality:** Council coordinates independent agent-team reviewers, grades reviews out of 10, and requests lead fixes and repeated fresh review rounds until the score target or round limit is met. The composer shows reviewer scores and rounds, supports reviewer navigation, and offers Keep fixing, Lower target, or Accept and finish when a decision is needed.
- **Upstream behavior changes:** Stale scores are invalidated when tracked work changes; cancelling Council setup clears pending state. Configurable target, maximum rounds, reviewer count and new-thread default are inherited. New Rust and browser test coverage and original [upstream release note](../0.3.103.md) were imported.
- **Source integrity:** Frozen fork [`174f0c0b17ae`](https://github.com/ginmp8/pandacode/commit/174f0c0b17ae1b036210cbc5dddf45f0701cd8b0); 41 upstream paths reconciled (9 additions, 23 identical replacements, 9 adapted shared paths). The nontruncated inventories contain 1,551 upstream blobs and 1,608 Extended blobs; 1,471 shared exact, 80 shared customized, 57 Extended-only, 0 missing and no mode differences. Existing Extended file-scope validation, settings and dependency remediations are preserved. Four overlapping textual tool-description hunks in `architect.rs` retained the Extended descriptions while `councilLens` was incorporated.
- **Verification status:** No local Node/Rust/native tests were run because direct Git access in this environment failed on DNS. The imported tests and source integrity are not live Council acceptance. CI must be read against the eventual documentation commit SHA, not the code checkpoint alone.
- **Inherited known limitations:** Paid-model review/fix loops and real-platform installers remain unverified; Council cannot observe changes outside PandaCode or shell/script edits that bypass file tracking.

The Extended distribution remains a **0.12.0 draft**, distinct from the upstream application version **0.3.103**. No tag, release, installer or npm publishing was performed.
