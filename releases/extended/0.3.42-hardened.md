# Hardened 0.3.42 — narrow thread and upstream release history

## Changes

- Port upstream 0.3.42's conversation layout correction: prevent sideways transcript scrolling and allow worker-line grids to shrink within narrow windows.
- Include the upstream Playwright regression case, without weakening existing tests.
- Backfill reference release notes 0.3.29–0.3.42 and label original versus Hardened history in the site changelog.
- Align product, npm lockfile, Tauri, and Cargo versions to `0.3.42-hardened`.
- Add a read-only upstream version monitor and manifest/provenance consistency tests.

## Limitations

This is a **source candidate**, not a signed installer or a full upstream 0.3.42 rebase. Original code ancestry remains 0.3.28 with selective additions; complete upstream feature parity is false. Existing hardened security paths and disabled updater/bootstrap controls are retained. Native compilation, full browser/WebKit, Windows/macOS installers and real provider tests were not performed in this environment. See [review](../../security-review/0.3.42-hardened/REPORT.md).
