# PandaCode Extended 0.4.0

PandaCode Extended now follows an independent release line. The distribution version is **0.4.0**, tracking the original PandaCode **0.3.42** release as a reference.

## What's new

- **GitHub task drafts:** Start fixes from GitHub issues as editable drafts with issue context attached to the task.
- **Board workflow:** Move tasks between Board stages by dragging cards and see stage indicators beside task titles.
- **Linked issue controls:** Optionally close or reopen a linked GitHub issue after an explicit on-screen confirmation.
- **Distinct desktop identity:** The application uses the PandaCode Extended name while preserving the original project's attribution and links.
- **Clearer release history:** Original PandaCode notes remain in `releases/`, while Extended and historical locally maintained notes live in `releases/extended/`.

## Release packaging

- **Strict Extended artifact identity:** Desktop release packaging accepts only matching `PandaCode Extended` bundles at technical version `0.4.0`. Original PandaCode bundles and mismatched bundle versions are rejected rather than redistributed as Extended.
- **Consistent version checks:** npm, Cargo and Tauri must agree on the three-component technical version `0.4.0`. The `+pc.0.3.42` suffix is informational display metadata, not a native bundle version.
- **Obsolete version handling:** The former four-component desktop release format is no longer used by new Extended release builds. Historical release records remain available for provenance.

## Version and compatibility

- **Extended version:** `0.4.0`
- **Full display identifier:** `0.4.0+pc.0.3.42`
- **Original PandaCode tracked reference:** `0.3.42`
- **Historical upstream source ancestry:** `0.3.28`

This Extended distribution incorporates selected upstream changes, but is **not** a full upstream 0.3.42 code rebase or a promise of feature parity. Its security controls, app data location, credentials and internal package identifiers remain unchanged. Consequently, installation alongside the official PandaCode app under the same application identity is not supported.

## Distribution and security

Automatic application and agent updates, network installers and automatic publishing remain disabled. Release notes describe a source candidate; they do **not** certify signed/native installers or completed tests on all platforms. Use the reviewed local build process and its checks before distributing binaries.
