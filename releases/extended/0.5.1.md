# PandaCode Extended 0.5.1

**Technical version:** `0.5.1`  
**Display version:** `0.5.1+pc.0.3.48`  
**Original PandaCode reference:** [0.3.48](https://github.com/aicodeking/pandacode/releases/tag/v0.3.48)

## Fixed

- Center the harness switch / `Conversation carried forward` disclosure inside the message column instead of offsetting it to the left. Keep long summaries readable and prevent overflow in narrow conversations.
- Add responsive regression coverage at desktop and narrower viewport widths.
- Preserve Extended-only features, existing security and local distribution restrictions.

## Build and validation

- Updated desktop, mobile, Cargo and Tauri versions to `0.5.1`. Historic releases, tags, attribution and source evidence are unchanged.
- Track the upstream 0.3.48 delta with the independent [incremental integration record](../../docs/upstream-integration-0.5.1.md); no complete upstream parity or native installer claim.
- Experiment with multiple parallel Playwright CI shards (with original coverage and repeated smoke checks retained). Actual performance gains depend on new CI measurements.
- This is a source release candidate, **not a published or installed release**.
