# PandaCode Extended 0.5.2

**Technical version:** `0.5.2`  
**Display version:** `0.5.2+pc.0.3.48`  
**Original PandaCode reference:** [0.3.48](https://github.com/aicodeking/pandacode/releases/tag/v0.3.48)  
**Status:** Unpublished source candidate.

## Fixed

- Apply active light/dark theme colors to native select dropdowns and options in Bot profile, other bot controls, Settings and shared select surfaces (#32).
- Add Board-card right-click stage actions to move idle tasks to Pending, Review or Completed, with feedback for prohibited transitions (#33).
- Clear UI references to deleted bot-owned sessions after Delete or Reset, avoiding stranded pending conversations and `Conversation not found.` (#34).

## Safeguards

- An active run or goal cannot be moved manually; In progress still requires starting an agent. Existing native guards remain intact.
- Linked GitHub issue close/reopen remains an explicit confirmation, independent of local stage transitions. Worktree cleanup retains user approval.
- Other bots, independent tasks, project files, security controls, permissions and upstream evidence are preserved.
- Tracked upstream reference remains 0.3.48; full upstream parity is not claimed.

## Validation and limitations

- CI must verify TypeScript, Node/release tests, Playwright, website and Rust; no green status is asserted by this note.
- Windows/WebView2 native dropdown rendering requires an on-device visual check in addition to automated computed-style tests.
- No tag, GitHub Release, published binary, merge or deployment is part of this candidate.
