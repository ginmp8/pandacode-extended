# PandaCode Extended 0.6.0

**Source candidate**, not a published release. Technical version `0.6.0`; display version `0.6.0+pc.0.3.48`.

## Changes

- Integrates the original PandaCode [0.3.48](https://github.com/aicodeking/pandacode/releases/tag/v0.3.48) harness-switch layout fix. The “Conversation carried forward” row aligns with the thread column and its summary/expanded description are centered, with bounded narrow-thread text.
- Adds desktop browser geometry regressions at 1440 px and 760 px.
- Tracks the upstream source note separately from Extended's independent version, with source identity in the [0.6.0 integration coverage](../../docs/upstream-integration-0.6.0.md).
- Retains Extended-only functionality and existing security policy, including explicit approvals, protected credentials, account isolation and disabled automatic updates.

## Provenance and limitations

The 0.3.48 release-note diff contains no new provider or remote protocol feature. This is a bounded 0.3.48 integration, **not** a full upstream rebase or a general all-platform parity certificate. Prior 0.5.0 source candidate notes and published 0.4.0 history remain unchanged. CI and real-device validation results must be recorded separately; no tests are claimed in this source note. No release tag, published build, update feed or installer is created by this integration.
