# PandaCode Extended 0.7.0

Status: integration candidate; not published.

## Scope

This candidate integrates the reviewed PandaCode 0.3.51–0.3.65 feature line while preserving PandaCode Extended security, Board/GitHub workflows, bots, approvals, local-first behavior, and independent release identity.

## Highlights

- Updated conversation typography, trace folding, final-reply actions, and responsive workspace chrome.
- Added Connect paging/compression/replay improvements with Extended authorization and revocation boundaries preserved.
- Added searchable, keyboard-accessible sidebar behavior and safer remote worktree fallback.
- Updated bots, shared channels, failover, action dock, Architect/workers/subagents, and Team/model selection flows.
- Added native Panda Router v4.3 foundations using the pinned PandaOrchestrator reference, with local heuristic fallback and explicit-only profiler acquisition.

## Security and compatibility

- No automatic updater, telemetry, unapproved external MCP, remote Full default, or unattended privilege expansion is enabled.
- Normal task/team routing never downloads model assets; optional profiler acquisition requires an explicit Settings action and verifies pinned SHA-256 hashes.
- Extended-only Board, GitHub issue/PR linkage, review/coordination, approval, bot deletion, and remote authorization behavior remains in scope for regression validation.

## Verification

This note does not claim publication or completed parity. The candidate must pass the repository build, unit/release/site tests, mobile/relay checks, Rust tests/clippy, browser regressions, security gates, and the 0.7.0 source-to-target coverage review before tracked upstream metadata advances to 0.3.65.
