## Current inherited source capabilities

These capabilities are present in the **initial source baseline**, inherited from PandaCode and earlier Extended integration work. They must **not** be presented as new 0.8.0-only additions without a verified release-to-release comparison.

- **Conversations:** the expanded `/btw` side-thread panel, independent model/effort/permission controls, steering, queuing, approvals, live tool activity, and message actions.
- **Multi-machine orchestration:** authorized agent launches on linked computers, automatic eligible-machine selection, lineage/child-thread controls, and offline-device handling.
- **OpenCode V2:** discovered model-specific reasoning variants and effort selection using the OpenCode V2 catalog and ACP configuration.
- **Desktop and harnesses:** Windows/Tauri stability and legacy-CPU compatibility adjustments; ZCode and pnpm-installed harness improvements; bot/team instruction and maintenance-command fixes.
- **Cloud and mobile:** fixes for supported cloud providers, OpenCode V2 cloud setup, private Docker upload staging, and the iOS keyboard inset.
- **Extended-only configuration and security:** opt-in controls for Connect and selected background/remote/cloud/MCP behavior, configurable bot pause, verified dependency remediations and data-migration compatibility, as detailed in the [feature controls](../../docs/extended/0.8.0/feature-controls.md) and [dependency security](../../docs/extended/0.8.0/dependency-security.md).
